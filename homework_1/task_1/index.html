ДЗ 1.1. Встановити IDE та вивчити список гарячих клавіш.

Встановити IDE та вивчити список гарячих клавіш.

Visual Studio Code:

Список гарячих клавіш:

Ctrl+P: Швидке відкриття файлу за назвою.

Ctrl+F: Пошук у поточному файлі.

Ctrl+Shift+F: Глобальний пошук по всьому проєкту.

F12: Перейти до визначення (Jump to definition) змінної чи функції.

Alt+стрілкавгору/вниз: Перемістити поточний рядок коду вище або нижче.Редагування та форматування

Ctrl+/: Закоментувати або розкоментувати виділений рядок коду.

Ctrl+Shift+K: Видалити поточний рядок.

Shift+Alt+стрілкавниз: Дублювати поточний рядок (або виділений блок) униз.

Shift+Alt+F: Автоматичне форматування коду.

Ctrl+D: Виділити наступний збіг такого ж слова, як зараз (дозволяє редагувати їх усі одночасно).Керування вікном та файлами

Ctrl+B: Сховати або показати бічну панель (Sidebar).

Ctrl+` (зворотний апостроф): Відкрити або закрити вбудований термінал.

Ctrl+\backslash : Розділити робочу область на два редактори поруч.Головні комбінації
